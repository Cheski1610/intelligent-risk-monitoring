# Limitaciones y uso responsable

- PaySim simula transacciones y no representa automáticamente una institución o población real.
- La etiqueta isFraud es una etiqueta sintética retrospectiva. No define una tasa de fraude real.
- Una anomalía estadística no es fraude confirmado; una alerta solo orienta revisión.
- isFlaggedFraud es una regla histórica incluida en el dataset, no una etiqueta independiente de verdad.
- Los campos de saldo muestran numerosas diferencias con respecto a reglas aritméticas simples; se mantienen como diagnóstico separado.
- Los identificadores de cuentas no son variables predictoras continuas ni se presentan como identidades reales.
- La muestra por step garantiza cobertura temporal y usa factores de expansión para estimar conteos. Percentiles y concentración en la muestra siguen sujetos al diseño de selección.
- Los límites se ajustan sin usar etiquetas del periodo final. La evaluación retrospectiva no demuestra desempeño futuro en otro entorno.
- El asistente usa documentos ficticios. Las referencias son pedagógicas, no políticas regulatorias ni asesoría legal.
- La generación de lenguaje puede cometer errores. Revise datos, citas, procedimientos y contexto antes de documentar conclusiones.
